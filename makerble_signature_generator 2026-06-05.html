How to install in Gmail
1
Fill in your details using the form on the left
2
Click "Copy signature HTML" in the top right — this copies the raw HTML code
3
Open Gmail → Settings (gear icon) → See all settings → Signature → Create new
4
Click inside the signature text box and paste (Cmd+V on Mac / Ctrl+V on Windows)
5
Scroll down and click Save Changes
Note: Images load from Google Drive. If they appear broken in the Gmail editor, don't worry — they will display correctly for recipients as long as the Drive files remain shared with "Anyone with the link".
